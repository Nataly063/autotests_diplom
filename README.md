Дипломный проект. Автоматизация теста к API для сервиса аренды самокатов.
Проект содержит автоматизированный тест для проверки работы API сервиса "Яндекс Самокат".
Тесты написаны на PYTHON с использованием библиотеки "requests" и фреймворка "pytest".

📂 Структура проекта
* `configuration.py` — содержит базовый URL тестового стенда и пути к эндпоинтам API.
* `data.py` — содержит тестовые данные (тело запроса для создания заказа).
* `sender_stand_request.py` — содержит вспомогательные функции для отправки запросов к API (создание заказа, получение заказа по треку).
* `create_order_test.py` — содержит непосредственно тест.
* `.gitignore` — список файлов и папок, исключенных из репозитория Git.
* `screenshorts` — скрины выполнения заданий 1 и 2 (работа с базой данных)
* `screenVSC` - скрин успешно выполненного теста со статусом PASSED.

Шаги автотеста:
1.Выполнить запрос на создание заказа.
2.Сохранить номер трека заказа.
3.Выполнить запрос на получение заказа по треку заказа.
4.Проверить, что код ответа равен 200.


⚙️ Настройка перед запуском
Перед запуском теста убедитесь, что в файле `configuration.py` указан актуальный `BASE_URL` вашего тестового стенда.
Текущий URL: https://c090fe8c-afe5-4d93-a5e9-0438a0504e78.serverhub.praktikum-services.ru 


Запуск теста:
В Терминале create_order_test.py выполнить команду:
pytest -v
При успешном выполнении тест получает статус PASSED.


Описание теста
В файле create_order_test.py реализован следующий сценарий:
1. Отправка POST-запроса на создание заказа (/api/v1/orders) с тестовыми данными.
2. Извлечение трека заказа из ответа.
3. Отправка GET-запроса на получение заказа по треку (/api/v1/orders/track).
4. Проверка, что код ответа равен 200 (успешное получение заказа).
